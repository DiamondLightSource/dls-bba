# BBA

**BBA** is the Python 3 implementation of the slow and fast BBA, originally written 
in Matlab.

## Installation

```bash
$ pipenv install bba
```

## Development

```bash
$ git clone git@gitlab.diamond.ac.uk:controls/python3/bba.git
$ cd bba
$ pipenv install -d
$ python setup.py install
```
